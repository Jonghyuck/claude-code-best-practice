## Tips

| ID | Text |
|---|---|
| new-user-warmup | 작은 기능이나 버그 수정부터 시작하고, Claude에게 계획을 제안하도록 한 뒤 제안된 편집 내용을 검증하세요 |
| default-permission-mode-config | /config를 사용해 기본 권한 모드(계획 모드 포함)를 변경하세요 |
| git-worktrees | git worktree를 사용해 여러 Claude 세션을 병렬로 실행하세요. |
| color-when-multi-clauding | 여러 Claude 세션을 실행 중인가요? /color와 /rename으로 한눈에 구분하세요. |
| memory-command | /memory를 사용해 Claude 메모리를 확인하고 관리하세요 |
| theme-command | /theme을 사용해 색상 테마를 변경하세요 |
| colorterm-truecolor | 더 풍부한 색상을 위해 환경 변수 COLORTERM=truecolor를 설정해 보세요 |
| powershell-tool-env | CLAUDE_CODE_USE_POWERSHELL_TOOL=1을 설정해 PowerShell 도구(미리보기)를 활성화하세요 |
| status-line | /statusline을 사용해 입력창 아래에 표시되는 커스텀 상태 표시줄을 설정하세요 |
| prompt-queue | Claude가 작업하는 동안 Enter를 눌러 추가 메시지를 대기열에 추가하세요. |
| enter-to-steer-in-relatime | Claude가 작업하는 동안 메시지를 보내 실시간으로 방향을 조정하세요 |
| todo-list | 복잡한 작업을 할 때는 Claude에게 할 일 목록을 만들어 달라고 해서 진행 상황을 추적하고 경로를 유지하세요 |
| ide-upsell-external-terminal | Claude를 IDE에 연결하세요 · /ide |

| permissions | /permissions를 사용해 bash, 편집, MCP 도구를 사전 승인하거나 사전 차단하세요 |
